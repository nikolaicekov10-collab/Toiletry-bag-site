## Разработка и повторяеми команди

Проектът използва Node.js >=22.13.0, Vite/Vinext, React и локален Cloudflare D1. Проверено е с Node 24.19.0 и npm 11.9.0. Запази TLS и проверките за целостта на пакетите.

Изпълнявай от корена на checkout-а:

```sh
bash scripts/sites-env.sh -- npm run install:ci
bash scripts/sites-env.sh -- npm run dev -- --port 5173
```

Помощните скриптове са записани без executable bit; външната Bash обвивка е необходима. Не сменяй системния HOME ръчно — скриптът настройва проектната среда.

Спрете dev сървъра преди build, след което го стартирайте отново. Едновременно изпълнение е довело до остарял виртуален модул във Vite.

```sh
bash scripts/sites-env.sh -- npm test
bash scripts/sites-env.sh -- node_modules/.bin/vite preview --host 127.0.0.1 --port 5173
```

`npm test` вече включва build. **`npm start` не е подходящ за тази Cloudflare компилация**: Node-only стартът не зарежда `cloudflare:workers`. Използвай Vite preview за компилираното приложение. Локалните адреси служат за вътрешни проверки; не ги представяй като публичен сайт.

За локален D1, ако липсва подготвената конфигурация, създай игнориран `.sites-runtime/local-d1.json` (след install):

```json
{
  "name": "toiletry-local",
  "compatibility_date": "2026-10-01",
  "d1_databases": [{
    "binding": "DB",
    "database_name": "site-creator-d1",
    "database_id": "00000000-0000-4000-8000-000000000000",
    "migrations_dir": "/workspace/Toiletry-bag-site/drizzle"
  }]
}
```

Адаптирай абсолютния `migrations_dir`, ако директорията е друга. UUID е локален placeholder, не идентификатор на продукционна база. Прилагай само локални миграции:

```sh
bash scripts/sites-env.sh -- node_modules/.bin/wrangler d1 migrations apply DB --local --config .sites-runtime/local-d1.json --persist-to .wrangler/state
bash scripts/sites-env.sh -- node_modules/.bin/wrangler types .sites-runtime/cloudflare.d.ts --config .sites-runtime/local-d1.json
bash scripts/sites-env.sh -- node_modules/.bin/tsc --noEmit --incremental false --types ./.sites-runtime/cloudflare
```

Повторното прилагане на миграциите е проверено: няма допълнителни миграции. `.sites-runtime/` и `.wrangler/` са игнорирани; процесите не се запазват между сесиите.

Оптимизираните снимки са в Git. След промяна на оригинали могат да се генерират отново с `node scripts/optimize-images.mjs`; използва `sharp`, инсталиран като зависимост на Next.
